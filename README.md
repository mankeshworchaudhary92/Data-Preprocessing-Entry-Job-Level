# Data Cleaning & Preprocessing with Python

## 📌 Project Overview

This project demonstrates a step-by-step data cleaning and preprocessing workflow using **Python, Pandas, NumPy, and Scikit-learn**.

The goal is to take a messy, real-world-style customer dataset, identify common data-quality problems, clean the data, and prepare it for further data analysis or machine learning.

---

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Jupyter Notebook

---

## 🔍 Data Cleaning Steps

The project covers several common data-quality problems:

1. Loading and inspecting the dataset
2. Checking dataset shape and structure
3. Standardizing column names
4. Removing duplicate records
5. Cleaning text values
6. Cleaning customer names
7. Cleaning email addresses
8. Cleaning phone numbers
9. Converting and validating dates
10. Handling invalid numeric values
11. Standardizing categorical values
12. Handling missing values
13. Fixing incorrect data types
14. Performing final data-quality checks
15. Saving the cleaned dataset

---


> **Note:** The raw customer dataset is not included if it contains personal or sensitive information.
